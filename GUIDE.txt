HR Dashboard - Installation and Usage Guide
=============================================

BAT Files Available:
--------------------

1. HR-Dashboard.bat    - Main menu (recommended)
2. quick-start.bat     - Quick start (install + run)
3. install.bat         - Install packages only
4. start.bat           - Start dev server only
5. build.bat           - Build production version
6. setup-and-build.bat - Full setup and build

=============================================

QUICK START (Recommended):
--------------------------

Double-click on: quick-start.bat

This file will automatically:
  - Check Node.js installation
  - Install packages (if needed)
  - Start the server
  - Open browser

=============================================

STEP-BY-STEP:
-------------

Step 1: Install packages
  -> Double-click install.bat
  -> Or in CMD: npm install

Step 2: Run project
  -> Double-click start.bat
  -> Or in CMD: npm run dev

Step 3: Access
  -> Browser: http://localhost:3000
