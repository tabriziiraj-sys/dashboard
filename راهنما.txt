📦 فایل‌های BAT موجود:

  1. HR-Dashboard.bat    → منوی اصلی (پیشنهادی)
  2. quick-start.bat     → شروع سریع (نصب + اجرا)
  3. install.bat         → فقط نصب پکیج‌ها
  4. start.bat           → فقط اجرای سرور
  5. build.bat           → ساخت نسخه Production

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🚀 روش سریع (پیشنهادی):

  روی فایل quick-start.bat دابل‌کلیک کنید.
  این فایل به‌صورت خودکار:
    • Node.js را بررسی می‌کند
    • پکیج‌ها را نصب می‌کند (در صورت نیاز)
    • سرور را اجرا می‌کند
    • مرورگر را باز می‌کند

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 روش مرحله‌به‌مرحله:

  مرحله 1: نصب پکیج‌ها
    → روی install.bat دابل‌کلیک کنید
    → یا در CMD: npm install

  مرحله 2: اجرای پروژه
    → روی start.bat دابل‌کلیک کنید
    → یا در CMD: npm run dev

  مرحله 3: دسترسی
    → مرورگر: http://localhost:3000
